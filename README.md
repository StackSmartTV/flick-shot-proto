# Flick Shot — 3D flick basketball prototype (WebGL build)

Play: https://stacksmarttv.github.io/flick-shot-proto/

Compiled Unity 6 WebGL build only (portrait, made for iPhone Safari). Swipe up on the ball to shoot; 60-second run.
Made shots trigger elemental effects: FIRE (3-pointers / ON FIRE streaks), LIGHTNING (swishes), KINETIC (bank shots), ICE (other makes).
All art is procedural; sounds are CC0 (Kenney, OpenGameArt) — see CREDITS.md.
